# wojturski-media

Media for the wojturski site.

Served over jsDelivr:

`https://cdn.jsdelivr.net/gh/andywojturski-lab/wojturski-media@main/reels/...`

Prefer a version pin when the `v1` tag exists:

`https://cdn.jsdelivr.net/gh/andywojturski-lab/wojturski-media@v1/reels/...`

## Layout

- `reels/preview/` — first 6 s (or the whole film if shorter), 720p, H.264 High, no audio, faststart, under 1.5 MB
- `reels/full/` — 1080p, H.264 High, AAC 128k when the source had audio, faststart, under 15 MB
- `reels/posters/` — `.webp` (quality 80) and `.jpg` fallback
